## Projects:  

#### Brave Linux debloat
Bash / Linux 

Brave Linux debloat is a simple bash script that fetch a .json file and copy it to `/etc/brave/policies/managed`.
This alllows the removal of unwanted Brave features such as the built in VPN or all the crypto wallet and more.  

Github: [naplon74/brave-linux-debloat](https://github.com/naplon74/brave-linux-debloat)  
Instalation command: `bash <(curl -fsSL https://raw.githubusercontent.com/naplon74/brave-linux-debloat/refs/heads/main/brave-debloat-linux.sh)`

#### Clean Me
Python / Gtk / Qt5  

Clean me is a simple app made for the lazy like me, it locks your keyboard and mouse so you can clean them without turning off your pc!  
Build with [Gnome builder](https://apps.gnome.org/Builder/) on Linux.  
Build using Python with [PyQt5](https://pypi.org/project/PyQt5/) on Windows.  
Both version are completly different but act the same. Launch the app, clean what you need to clean, press `Ctrl` + `Alt` + `S` and the screen unlocks.  

Github: [Windows](https://github.com/naplon74/CleanMe/tree/windows) - [Linux (.flatpak)](https://github.com/naplon74/CleanMe/tree/linux) - [Download](https://github.com/naplon74/CleanMe/releases)
