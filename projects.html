gitRE

Simple multi-repository git status tool for Linux. It scans your system for git repositories, collects their status, and displays a clean summary.
Download via curl, dnf for Fedora 44+ or portable install (tar.gz and rpm file).
Version 1.3 brings a new CLI tool that will receive new feature with every update. use gitRE --help for more information
